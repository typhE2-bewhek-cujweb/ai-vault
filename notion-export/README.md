# Notion 移行用ドロップゾーン

Notion からエクスポートした .md をこのフォルダに放り込む。

## Notion 側のエクスポート手順
1. Notion 左上のワークスペース名 → **Settings** → **Export all workspace content**
   （ページ数が少なければ、各ページの Export → Markdown でOK）
2. フォーマット：**Markdown & CSV** を選択
3. ダウンロードした zip を展開して、中身を**このフォルダ**に置く

統合が完了したら、このフォルダは削除します。
