# offline/ — オフライン作業の置き場所

新幹線・機内など、ネットにつながらない間の成果物と作業メモを置く。
オンラインに戻ったら、Claude がここを読んで引き継ぐ。

## 使い方
1. 作業を始めたら `_TEMPLATE.md` を複製し、`YYYYMMDD_件名.md` として作業メモを作る
2. 成果物（下書きなど）は同じ名前で始まるファイルにする（例：`20261015_防衛省提案_下書き.md`）
3. オンラインに戻ったら、Claude に「offline の引き継ぎをして」と頼む

## オフラインで使えるもの
- LM Studio のチャット（プリセット「業務_標準」を選ぶ）
- `python3 tools/local_llm.py "依頼文"`（ターミナルから。自動で Mac 自身 127.0.0.1 につながる）
- Obsidian（vault の閲覧・編集）、Bionic（ローカルモデル設定時）

## 引き継ぎ後
Claude が処理したメモは、状態を「引き継ぎ済み」に変える。ファイルは削除しない。
