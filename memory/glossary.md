# 用語集

ローカルLLMが用語を取り違えないための定義。追記のみ（形式：`- **用語**：説明`）。

## 事業・製品
- **ドローン**：無人航空機（UAV）。「ローン（融資）」とは無関係
- **エンジンドローン**：エンジン（内燃機関）を動力源とする無人航空機。電動（バッテリー）ドローンより長時間・重量物の運搬に向く
- **AZ-250**：エンジンドローンBIZ部が量産化を進めるエンジンドローンの機種名
- **AAA**：アラセ・アイザワ・アエロスパシアルの社内略称（対外資料では正式名称）
- **エンジンドローンBIZ部**：株式会社椿本チエイン 新ビジネス事業部内の部署。エンジンドローンの事業化を担う

## 認証・制度
- **型式認証**：国土交通省による無人航空機の機体の型式ごとの安全性の認証
- **NK**：一般財団法人 日本海事協会（無人航空機の検査機関としての文脈で使う）

## 関係機関
- **陸自／JGSDF**：陸上自衛隊
- **陸幕**：陸上幕僚監部
- **東京消防庁**：消防技術研究開発センターとエンジンドローンの共同研究を行う相手先
