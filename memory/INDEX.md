# INDEX — 記憶ファイルのガイド

| ファイル | 中身 | 更新タイミング |
|---|---|---|
| `../MEMORY.md` | 入口：現在の目標・次の手 | 毎セッション末 |
| `goals.md` | 長期目標・方針 | 変更時（まれ） |
| `decisions.md` | 決定ログ（追記のみ） | 判断した時 |
| `journal.md` | 作業手記（膨らんだら圧縮） | 毎セッション末 |
| `projects/` | プロジェクト別の状態 | その作業中 |

## 書式慣例
- 日付は `YYYY-MM-DD`
- 著者は `(Qwen)` / `(Claude)` / `(user)` の表記
- 追加は常にファイル末尾に（時系列が壊れないように）
